# Database views

The four ways Rotion draws a Notion database. Each page fetches the same sample database with `FetchDatabase` and hands it to a different component. How to use them is in [Database views](/database-views).

| View | Component |
| --- | --- |
| [Table view](/views/table) | `Table` |
| [List view](/views/list) | `List` |
| [Gallery view](/views/gallery) | `Gallery` |
| [Calendar view](/views/calendar) | `Calendar` |
