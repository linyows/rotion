# データベースビュー

Rotion が Notion のデータベースを描画する 4 つの方法です。
どのページも同じサンプルデータベースを `FetchDatabase` で取得し、別々のコンポーネントに渡しています。
使い方は[データベースビュー](/ja/database-views)にあります。

| ビュー | コンポーネント |
| --- | --- |
| [テーブルビュー](/ja/views/table) | `Table` |
| [リストビュー](/ja/views/list) | `List` |
| [ギャラリービュー](/ja/views/gallery) | `Gallery` |
| [カレンダービュー](/ja/views/calendar) | `Calendar` |
